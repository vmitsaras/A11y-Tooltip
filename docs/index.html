Four placements, one interaction model

No click-to-toggle behavior. Interactive floating content belongs in a popover or dialog.

Useful context placed above the trigger. The trigger keeps focus while this description is visible. Escape dismisses the tooltip without moving focus. Hover can move from the trigger onto this tooltip.

Accessibility contract

Use the right pattern

  • The trigger must be keyboard-focusable and independently named.
  • The tooltip is descriptive content referenced by aria-describedby.
  • The tooltip never receives focus and must not contain interactive controls.
  • Essential instructions should stay visible rather than living only in a tooltip.
